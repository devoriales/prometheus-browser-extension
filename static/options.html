PromQL AI Assistant

Ask AI to write, fix and explain PromQL on your Prometheus pages. The assistant looks up your real metric and label names and tests each query before giving it to you.

1. How to connect to Claude

Requests go to <base URL>/v1/messages.

Opus 5.5 gives the best queries. Sonnet 5.5 and Haiku 5.5 are faster and cheaper.

One-time setup. Install the bridge from the extension folder:


      
This needs Node.js and a logged-in claude CLI (run claude and /login once). The bridge runs claude -p with all tools turned off, so Claude can only answer in text.
